This script was created to automate the process of redacting sensitive company and customer information from my sales report project to make it shareable on LinkedIn. It opens the PDF from its copied path, and permanently redacts customer names, order amounts, and the cumulative sales revenue, then saves it to a new PDF that can be safely shared.

PLEASE NOTE This script was sanitized so that specific details within the script did not interfere with company privacy. This is not the exact script that was ran during the project, it is the same format but has placeholders for private details.
